# Contributing

Install Node 22.12+ and run `npm ci`, `npm run dev`, and `npm run check`. Keep the core dependency-free and browser globals out of module initialization. Changes to options must update API docs, plain-text agent docs, adapters, and meaningful tests.

Report rendering bugs with browser/version, OS/device, a minimal reproduction, ancestor CSS, requested options, and a screenshot if useful. A CSS supports result alone is not proof of rendered refraction. Label proposals clearly and include actual measurements for performance claims.

Good first contributions: verified minimum-peer compatibility, real-device rendering reports, application recipes, contrast demonstrations, or translated documentation. Ask in an issue before adding a renderer or runtime dependency.

# Repository guidance

This is an independent web material library. Maintain the portable CSS default and explicit experimental refraction tier. Do not claim Apple's pixel-identical rendering, universal refraction support, published URLs/packages, or benchmarks without evidence.

Keep the core free of runtime dependencies and import-safe during SSR. React and Vue remain optional peer entrypoints. Preserve semantic controls. Options, agent guides, integration recipes, and docs must agree.

Run `npm run check` after functional changes and `npm pack --dry-run` after packaging changes. Use the T3 collaborative preview for live browser work when available. Record browser validation separately from unit tests. Keep promotions honest and tied to published, working artifacts.

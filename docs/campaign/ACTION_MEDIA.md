# Review Room action film

Original 12-second, 960 × 960 H264 High/yuv420p film with 360 decoded frames at 30 export fps and AAC LC stereo/48 kHz. Original 160 BPM drum-and-bass/FM score, seed 32, uses procedural synthesis without external samples. Original SVG artwork, interface, code and score are MIT; no external UI, font or media asset was copied.

The native T3 source-preview film follows the actual finite 11-second local workflow: confirmed queue entry, local duplicate rejection, explicit retry of changed fields, recorded intent without queue confirmation, client cancellation, later noncooperative local commit, and a real local review state change. The interface names the finite local fixture and does not imply a server or review service. AbortSignal is cancellation intent; it cannot undo a host write. The cancelled client state remains cancelled after the late local entry appears.

Separate native checks covered required-field and URL validation, associated submitter serialization, single flight, focusable busy controls, retained dirty values and native field/button/icon identity, retry with current values, submitted blocking, cooperative cancellation and stale UI state after a host commit. Real T3 Enter submission invoked one callback with the queue submitter. Active-paint recording confirmed the finite pending indicator changes transform and stops after completion; the native quiet toggle suppresses it.

Three actual states in each of five CSS viewports (320 × 700, 390 × 844, 768 × 1024, 844 × 390, 1440 × 900) produced no horizontal overflow, no action/associated checkbox target below 44 px, and no form field below 16 px text or 44 px height. These are desktop Chromium layout checks, not physical-phone, soft-keyboard, Safari or assistive-technology validation.

The standalone minified IIFE action helper measured 5,948 raw bytes / 2,402 gzip bytes. Native connected-controller attach + destroy timing used 400 batches of 20 cycles and 50 warmup cycles per variant, with fixtures and options created outside the timed region. Button and form batch averages measured approximately 0.005 ms median / 0.010 ms p95 per cycle. Timer quantization remains visible; these batch percentiles exclude async host fixtures, invocation, network, style/paint and any comparative speedup. They do not measure input latency or app FPS.

Temporary camera-only density compacts the original header, form, cards and receipt, makes the read-only queue a 305 px scrolling viewport, and hides lower explanatory sections/footer. It retains the actual native controls and outcomes. Finite camera scrolls at 1.2 / 4.5 / 6.25 / 8.4 / 9.8 seconds reveal actual appended queue entries. The film has no substituted data or simulated results. Frames at 0.8 / 3.5 / 8.6 seconds were visually reviewed; full video/audio decode passed with exactly 360 video frames. Export frame rate is not application FPS.

Liquid Glass Kit 0.10 moves optimization into the rendering pipeline and adds a flowing field of 3,000 decorative glass instances.

The optional WebGL2 scene reuses one full-resolution wallpaper texture, shares trigonometric phases and batches bounded HTML lenses. Fields add stream, wave and orbit motion in one instanced draw; no particle DOM or per-frame transform uploads. Existing semantic CSS controls, optional adapters, lens options and lifecycle remain. Native context restoration is fixed; explicit pixel budgets, pause and reduced preferences remain available.

Measured native Chrome 152 / Apple M1 Pro, equal 1280×800 backing resolution, five paired runs: eight-lens GPU median **1.5827 → 0.8455 ms (46.6% less GPU time)**; moving lenses **1.5800 → 0.8552 ms (45.9% less)**. Separate eight-map CPU generation: **16.8 → 4.1 ms (75.6% less)** across 31 paired batches, preserving bitmap bytes. Callback cadence remains near 60 Hz for both versions; no whole-app, phone, battery or FPS improvement is claimed.

Cached RGBA8 sampling and bounded ordered blending change interpolation, quantization, edge sampling and bright overlapping rims. Existing functionality remains, but pixel-identical rendering is not promised. Fields sample their own procedural wallpaper, never arbitrary DOM; their count is submitted graphics, not thousands of semantic widgets.
